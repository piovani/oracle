From B3 quotes to the daily plan

Four commands split the work: sync loads the history into the database, recommend builds tomorrow's plan, backtest tests the same rule on past data, and api serves the data, the rule and the plan over HTTP. Pick a command to see its path.

Flow

One trade, session by session

Everything is measured in ATR, the average daily range over the last 14 sessions, starting from the close of the signal day. The example below is illustrative.

above the 200-day average RSI(2) < 10 median volume ≥ R$5M/day exit within 5 sessions

What must not break

No look-ahead

In the backtest, every decision on day D uses only what was known at the close of D. A stock's track record only counts trades that had already ended by then.

Splits break the series

Prices are not adjusted. A close-to-close change below 0.6× or above 1/0.6× is treated as a split or reverse split, and the series is cut there.

One rule

recommend, backtest and the API call the same internal/swing functions. Change the rule and all of them change together, so the backtest keeps measuring the real plan.
